HITITFINLEX - WINDOWS KURULUMU
================================

Bu paket yalnizca frontend kaynak kodudur. Mevcut backend ve veritabaninizi degistirmez.

GEREKENLER
----------
1. Node.js 22 veya daha yeni bir surum
2. Calisan HititFinLex FastAPI backend'i
3. PostgreSQL, Ollama ve model servislerinin daha once kurdugunuz sekilde hazir olmasi

1) PAKETI ACIN
---------------
ZIP dosyasini su klasore acin:

C:\Users\PC\Documents\HititFinLex

2) BACKEND'I BASLATIN
---------------------
Yeni bir CMD penceresi acin ve sirayla calistirin:

cd /d C:\Users\PC\Documents\katilim_finans_app
.venv\Scripts\activate
set PYTHONUTF8=1
uvicorn api:app --reload --host 127.0.0.1 --port 8000

Bu pencere acik kalmali.

3) FRONTEND AYARINI OLUSTURUN
-----------------------------
Yeni bir CMD penceresi acin:

cd /d C:\Users\PC\Documents\HititFinLex
copy .env.example .env.local

.env.local icinde su satir bulunmali:

NEXT_PUBLIC_API_BASE_URL=http://127.0.0.1:8000

4) PAKETLERI KURUN
------------------
Ayni CMD penceresinde:

npm ci

5) FRONTEND'I BASLATIN
----------------------

npm run dev

Terminalde hazir mesaji gorundugunde tarayicida su adresi acin:

http://localhost:3000

6) TARIHSEL VERIYI KONTROL EDIN
-------------------------------
- Genel bakista Birlesik / Guncel / Arsiv secenekleri gorunmeli.
- Toplam veri envanteri 3.351 kayit gostermeli.
- Urun katalogunda Tarihsel secip en az iki karakterli bir sorgu yazin.
- Karsilastirmada Tarihsel secip Son 1 ay veya Son 3 ay secin.
- Akilli asistanda Tarihsel secip bir donem belirleyin.

7) TUM BANKALAR PANOSUNU KONTROL EDIN
-------------------------------------
- Karsilastirma ekraninda banka secimini bos birakin veya "Tum bankalar" secenegine basin.
- Bir urun turu secip "Tum bankalari karsilastir" dugmesine basin.
- Kartlar / Matris dugmeleriyle iki farkli gorunum arasinda gecin.
- Akilli asistana "Konut finansmaninda en uzun vadeleri karsilastir" diye sorun.
- Yanittan sonra "Tum bankalar panosu" gorunmeli; verisi olan her banka ayri kartta listelenmelidir.
- Asistan urun turunu algilamazsa ustteki "Urun panosu" menusunden urunu elle secin.

SORUN GIDERME
-------------
API cevrimdisi gorunuyorsa:
- Backend CMD penceresinin acik oldugunu kontrol edin.
- http://127.0.0.1:8000/health adresini tarayicida acin.
- Frontend'i kapatip yeniden baslatin: Ctrl+C, sonra npm run dev

Port 3000 doluysa Next.js otomatik olarak 3001'i kullanabilir. Terminalde yazan adresi acin.
